AI 기반 개인정보 보호 플랫폼 — PIILOT

기업 인프라에 산재된 개인정보를 AI 모델로 자동 탐지하고 비식별화하여 보안 및 법적 리스크를 최소화하는 통합 관제 플랫폼. 개인정보 유출을 사전에 방지하고 탐지하는 AI 기반 파일럿 관제 플랫폼.

Overview

기업 환경에서 DB, 파일 시스템, 문서 등에 분산 저장된 개인식별정보(PII)를 AI 모델이 자동으로 탐지하고 비식별화하는 통합 관제 플랫폼이다. 문서·이미지 하이브리드 비식별화 파이프라인을 설계하고, 2단계 XGBoost 분류 아키텍처로 DB 레코드 암호화 여부를 판별한다.

AI 학습용 PII 합성 데이터셋(8,500개)을 설계·동적 생성하였으며, 특정 PII에 대한 오버피팅을 방지하기 위해 동적 가중치 알고리즘으로 8개 클래스 균형을 확보하였다. 최종적으로 KT AIVLE School 8기 AI 트랙에서 대상(1위)을 수상하였다.

Approach

AI — PII 합성 데이터셋 설계 및 동적 생성

  • AI 학습용 PII 합성 데이터셋 설계 및 동적 생성 (8,500개)
  • 특정 PII 쏠림 현상 방지 — 동적 가중치 알고리즘으로 8개 클래스 균형 확보

AI — 문서/이미지 하이브리드 비식별화 파이프라인

  • 문서·이미지 형식을 모두 처리하는 하이브리드 비식별화 파이프라인 설계

AI — DB 레코드 암호화 여부 판별 모델 (2단계 XGBoost)

  • 1차 분류(이진): 입력 레코드가 계좌번호인지 그 외 값인지 우선 판별하여 혼동 클래스 분리
  • 2차 분류(다중): 분리된 데이터를 바탕으로 7종의 PII 또는 NONE으로 세분화하여 최종 암호화 여부 판별
  • 50여 개의 은행 코드 패턴, 유효 계좌 길이 등 금융 및 보안 도메인 지식을 반영한 파생 변수 추가
  • 최종 정확도 94.4% 달성 (전체 테스트 84/89)

BE — 백엔드 API 구현

  • 파일 개인정보 목록 API 구현
  • 개인 알림 시스템 API 구현
  • QuerydSL 도입으로 복잡한 조건 필터링과 통계를 효율적으로 집계
  • 알림 목록 COUNT 쿼리 병목을 Slice 기반 페이징으로 전환하여 DB I/O 성능 개선
Role (팀원) AI: PII 합성 데이터셋 설계 및 동적 생성, 문서/이미지 하이브리드 비식별화 파이프라인 설계, DB 레코드 암호화 여부 판별 모델(2단계 XGBoost) 구축  |  BE: 파일 개인정보 목록 API 구현, 개인 알림 시스템 API 구현

Tech Stack

Python HuggingFace XGBoost Java 21 Spring Boot 3.5 PostgreSQL Redis PII Detection 데이터 비식별화 2-Stage Classification

Team

KT AIVLE School 8기 AI 트랙 — AI: 6명, BE: 4명, FE: 2명, Infra: 2명 (총 14명)

Results

  • DB 레코드 암호화 여부 판별 모델 최종 정확도 94.4% 달성
  • 개인정보 비식별화는 미탐(FN)이 법적 리스크로 직결됨 — Precision 하락을 감수하더라도 Recall 극대화를 목표로 F2 Score를 기준 지표로 채택
